AWS Glue Interactive Sessions now support Apache Spark Connect, enabling developers to build and run Spark applications from environments like SageMaker Unified Studio notebooks, Jupyter, and Visual Studio Code while executing on Glue's serverless infrastructure without cluster management. Spark Connect uses a thin client architecture decoupling client applications from the Spark execution environment.
