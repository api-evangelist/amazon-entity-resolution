AWS Security Agent, now part of AWS Continuum, includes threat modeling, an AI-powered agentic capability that automatically generates threat models from design documents or application source code using the STRIDE framework. Available in public preview, it analyzes architecture, data flows, and trust boundaries and produces contextually relevant threat models with actionable mitigations across all six STRIDE categories.
