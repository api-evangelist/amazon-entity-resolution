AWS Sign-in now supports resource-based policies and resource control policies for the AWS Management Console, letting users restrict console sign-in to expected networks. Resource-based policies apply to individual AWS accounts and resource control policies apply organization-wide through AWS Organizations, and can be combined with AWS Management Console Private Access.
