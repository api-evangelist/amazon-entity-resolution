AWS Security Agent, now part of AWS Continuum, adds Kiro and Claude Code support, enabling developers to trigger security scans directly from their development environment. It now validates code scanner findings by simulating exploits in sandbox environments and providing exploit proof, and adds GitLab.com, GitLab Self Managed, GitHub Enterprise, Bitbucket, and Confluence integration support.
