Amazon Aurora MySQL-Compatible Edition and Amazon RDS for MySQL now provide RDS Extended Support for MySQL 5.7 through June 30, 2029, shifting from the previous February 28, 2027 end date. This applies to Aurora MySQL version 2 and RDS for MySQL version 5.7, providing security patches and bug fixes with no price increase as customers continue Year 3 pricing.
