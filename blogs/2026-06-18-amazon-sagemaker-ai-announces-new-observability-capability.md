Amazon SageMaker AI introduces observability capabilities providing visibility into token performance, GPU health, inference component placement, and autoscaling behavior for generative AI inference workloads. A new pre-built SageMaker AI Insights dashboard in Amazon CloudWatch displays Time to First Token, inter-token latency, GPU utilization, scaling events, and cold start breakdowns with OpenTelemetry-native metrics published automatically.
