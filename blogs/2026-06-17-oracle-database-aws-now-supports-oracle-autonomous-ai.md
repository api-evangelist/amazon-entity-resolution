Oracle Database@AWS now supports Oracle Autonomous AI Database Serverless (ADB-S), a fully managed Oracle database service on Exadata infrastructure that automatically handles patching, tuning, and scaling. ADB-S supports four workload types (AI Transaction Processing, AI Lakehouse, AI JSON Database, and Oracle APEX) and integrates with AWS KMS, Amazon CloudWatch, and Amazon EventBridge.
