Amazon Bedrock Guardrails now provides the InvokeGuardrailChecks API, a resourceless API enabling individual safeguard application at any agentic AI application point without creating guardrail resources. It offers granular per-request control returning numeric severity and confidence scores, supports content filters, prompt attack detection, and sensitive information filters, and operates in detect-only mode.
