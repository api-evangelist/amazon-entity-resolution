Amazon S3 Vectors can now return up to 10,000 similarity search results per query, a 100x increase from the previous limit. This is valuable for multi-stage retrieval pipelines needing reranking, aggregations, or deduplication; users update application code to specify up to 10,000 topK results in QueryVectors API requests, with results returned across pages.
