Amazon GameLift Servers now supports container fleet improvements including Linux capability customization (such as NET_RAW and SYS_PTRACE) and a new ListContainersNetworkInfo() server SDK action for retrieving container network information. These enable automatic service discovery and simplified communication between game servers and auxiliary services.
