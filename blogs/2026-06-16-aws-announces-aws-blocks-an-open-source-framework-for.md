AWS announces AWS Blocks public preview, an open-source TypeScript framework enabling developers to build backend capabilities on AWS without learning infrastructure tools. It runs a fully functional local environment with Postgres, authentication, and real-time messaging requiring no AWS account, and identical application code runs on production AWS services with zero changes, with the option to drop into AWS CDK.
