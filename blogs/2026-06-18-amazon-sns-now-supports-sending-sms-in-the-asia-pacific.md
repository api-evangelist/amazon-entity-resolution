Customers using Amazon Simple Notification Service in the Asia Pacific (Seoul) Region can now transmit text messages to subscribers across more than 200 countries and territories. SNS users in Seoul can subscribe phone numbers to SNS topics and broadcast SMS messages via AWS End User Messaging.
