AWS HealthOmics now streams workflow engine logs to Amazon CloudWatch in real time, enabling customers to monitor workflow execution progress as it occurs. Streamed engine logs provide visibility into orchestration events, task scheduling, import/export activity, and complete error stack traces for Nextflow, WDL, and CWL workflow runs.
