AWS announces business context and semantic search preview for AWS Glue Data Catalog, helping discover and understand data by semantic meaning. Users enrich Glue Data Catalog tables, including those backed by S3 Tables, with glossary terms and custom metadata, and the new Glue Search API finds data by semantic meaning.
