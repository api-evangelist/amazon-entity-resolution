AWS DevOps Agent now provides a release management capability in preview, reviewing code changes for release readiness and executing autonomous release testing. Release readiness review checks for internal standard drift, dependency impacts, and access controls, while release testing generates and runs test plans for web and API-based applications in customer-provisioned environments.
