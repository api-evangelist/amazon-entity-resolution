Amazon CloudWatch Synthetics announces multilocation canary support, enabling developers and SREs to execute identical canaries across multiple AWS Regions simultaneously from a single management point. Users create and manage a canary in one primary Region, and CloudWatch Synthetics automatically replicates it to chosen additional Regions, consolidating all run data, metrics, and artifacts.
