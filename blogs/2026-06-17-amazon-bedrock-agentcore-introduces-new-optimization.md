AWS announces new Amazon Bedrock AgentCore optimization capabilities converting production traces into continuous agent improvement through failure, intent, and trajectory insights, plus recommendations, batch evaluations, and A/B testing. Recommendations analyze traces and evaluation outputs to suggest specific system prompt and tool description improvements grounded in actual agent behavior.
