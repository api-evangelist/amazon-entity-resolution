AWS announces Ubuntu 24.04 LTS bundle availability for Amazon WorkSpaces Personal in the AWS China (Ningxia) Region, operated by NWCD. The bundle provides updated Linux packages, an enhanced security posture, and a migration pathway for customers running older Amazon Linux 2 WorkSpaces.
