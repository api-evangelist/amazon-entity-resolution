AWS announces general availability of the managed agent harness in Amazon Bedrock AgentCore, which executes the orchestration loop, runs tools, manages context window, persists state across turns, recovers from failures, and isolates each session. Customers define an agent in configuration and AgentCore assembles and runs the loop in an isolated environment, and can export the harness to Strands-based code via a single CLI command.
