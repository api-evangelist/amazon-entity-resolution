Web Search on Amazon Bedrock AgentCore is now generally available, a fully managed tool enabling agents to ground responses in current web knowledge within secured AWS environments with zero data egress. It uses a multi-source grounding approach combining Amazon's web index with structured knowledge graph data and is exposed as a built-in connector target on AgentCore gateway using the Model Context Protocol.
