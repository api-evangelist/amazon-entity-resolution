Amazon MQ for RabbitMQ now supports private networking, enabling brokers to connect to private VPC resources without public exposure. This helps organizations reach private identity providers such as LDAP and OAuth 2.0, other RabbitMQ brokers, or self-hosted brokers using Amazon VPC Lattice, AWS Resource Access Manager, and AWS PrivateLink.
