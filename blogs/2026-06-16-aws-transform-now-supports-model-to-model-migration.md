AWS Transform now provides a model-to-model migration custom transformation that assesses generative AI workloads and produces migration plans for transitioning third-party providers to Amazon Bedrock. The AI-powered agent scans codebases, identifies every AI SDK and model in use, and maps models to Bedrock equivalents with cost comparisons and production-ready code changes, supporting OpenAI, Google Gemini, Anthropic SDK usage, and open-source models via LiteLLM or Ollama.
