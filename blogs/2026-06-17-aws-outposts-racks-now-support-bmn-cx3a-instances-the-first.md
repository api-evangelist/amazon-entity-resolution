date: "2026-06-17"

AWS announces bmn-cx3a instance availability on second-generation AWS Outposts racks, featuring 5th Generation AMD EPYC processors up to 4.1 GHz and NVIDIA ConnectX-7 NICs delivering up to 800 Gbps bare-metal accelerated network bandwidth. Instances offer up to 256 cores and 1.5 TB memory across bmn-cx3a.metal-32xl and metal-64xl sizes with 2x 8 TB NVMe SSD storage.
