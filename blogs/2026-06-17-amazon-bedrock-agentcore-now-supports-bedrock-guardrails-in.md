AWS announces Amazon Bedrock AgentCore now supports Bedrock Guardrails in policy, providing deeper safety and security controls for scaling AI agents in production. Guardrails evaluate every authorized agent action output and every gateway target call input in real-time, detecting and blocking prompt injection attacks, harmful content, and sensitive information exposure.
